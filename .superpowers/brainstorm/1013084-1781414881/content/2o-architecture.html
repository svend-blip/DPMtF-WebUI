Fase 2O-a: Parallel-kørsler (nu)

Workflow per comparison run:

  1. Cloud model (denne session) eksekverer prompt → resultat registreres i prompt_runs
  2. Samme prompt sendes via tmux bridge til lokal model (review_claude)
  3. Lokal model eksekverer → skriver result.md → cloud reviewer
  4. Cloud model registrerer lokal models resultat i prompt_runs
  5. Sammenligning: success, duration, tokens, cost, output quality → noter i prompt_runs
