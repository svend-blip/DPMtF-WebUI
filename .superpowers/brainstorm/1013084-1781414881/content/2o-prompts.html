2O: Hvilke prompts til parallel-kørsel?

Vi har brug for opgaver begge modeller kan køre — så vi får sammenlignelige data

A

Genbrug v3 alignment prompts

Kør Prompt #1, #2, #4 (docs, lbl, README) på begge modeller. Lokal model har allerede kørt dem — vi har data. Cloud model kører samme prompts og vi sammenligner: success, duration, tokens, cost, kvalitet.

Fordel: Direkte sammenlignelig — samme opgave, forskellig model.

Ulempe: Cloud model har set prompts før (bias).

B

Nye opgaver — friske for begge

Design 3 nye prompts som ingen af modellerne har set. F.eks: tilføj en ny lille feature til v3, opdatér governance doc, fix en bug. Begge modeller kører samme prompt fra scratch.

Fordel: Ren sammenligning — ingen bias.

Ulempe: Kræver nye opgaver at designe.

C

Blandet — 1 genbrug + 2 nye

1 prompt fra v3 alignment (f.eks. Prompt #4 README — den simpleste), 2 nye opgaver. Giver både direkte sammenligning og friske data.

Fordel: Både bias-check og rene data.
