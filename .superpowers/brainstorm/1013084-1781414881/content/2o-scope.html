2O: Hvad skal bygges?

Vi har allerede bridge + 6 prompts. Hvad mangler for at 2O er "færdig"?

A

Lightweight — Formaliser processen

2O = dokumentation + 3-5 parallel-kørsler med eksisterende værktøjer. Cloud model kører prompt → samme prompt sendes via bridge til lokal model → resultater sammenlignes manuelt → data registreres i prompt_runs. Ingen ny kode i DPMtF-WebUI.

Output: Baseline-data i prompt_runs + opdateret model decision tree.

B

Dashboard — Comparison panel i DPMtF-WebUI

Nyt "Model Comparison" panel i System Setup drawer. Viser side-by-side resultater for cloud vs lokal på samme prompt. Ny comparison_runs tabel. Automatisk farvekodning (grøn=cloud bedre, blå=lokal bedre, grå=ens).

Output: Frontend-panel + API + database + baseline-data.

C

Hybrid — Data nu, panel senere

Fase 2O-a: Kør 3-5 parallel-kørsler nu med bridge'en. Registrér struktureret i prompt_runs med comparison metadata. Opdatér model decision tree.

Fase 2O-b: Byg comparison panel baseret på erfaringerne fra 2O-a.

Output: Baseline-data først, panel derefter.
