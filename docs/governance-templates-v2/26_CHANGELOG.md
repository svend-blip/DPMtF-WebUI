# 26 — CHANGELOG

> **en-US is the standard language for all governance-templates-v2 files.**
> All changelog entries MUST be in English (en-US).

## Purpose

Append-only history of all notable changes organized by date and phase.
This is the project's timeline of what was done and when.

## When to Use

- **All roles:** Record completed work at the end of each phase.
- **After `/clear`:** Reference to understand project history.
- **Architect:** Review before designing new features.

## Rules

1. **Append-only** — add new entries at the bottom. NEVER edit or remove
   existing entries.
2. **Format:** `### [YYYY-MM-DD] — [Phase Key]: [Brief Description]`
3. **Each entry MUST include:**
   - Changed/Added: What was changed or added.
   - Fixed: What bugs were fixed.
   - Removed: What was removed (if anything).
4. **Include commit hashes** for significant commits.
5. **All entries MUST be in English (en-US).**
