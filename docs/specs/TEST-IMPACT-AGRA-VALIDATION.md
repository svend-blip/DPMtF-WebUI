## Engine findings (reported, not fixed — per GOAL §4 / §9.4)

1. **Over-conservative collect-check** in
   `scripts/testing.runner._collect_tests`. The check returns False
   whenever `pytest --collect-only` output contains the substring
   `error`; test names like
   `tests/test_import.py::test_import_records_chronology_error_as_conflicts_row`
   trigger false positives. `runner.run_plan()` therefore returns
   `status=ERROR` with `duration_seconds=0.0` even when the
   underlying pytest execution runs cleanly. The defect is in the
